# 파일조직도

src/
├── app/                  # [라우팅] 주소창의 경로가 결정되는 곳
│   ├── (main)/           # 홈 화면 (URL: /)
│   ├── auth/             # 로그인 및 카카오 인가 처리 (/auth)
│   ├── trip/[id]/        # 여행 상세 페이지 (/trip/1, /trip/2 ...)
│   ├── settle/           # 정산 로직 및 결과 (/settle)
│   └── layout.tsx        # 전체 레이아웃 (공통 헤더, 바텀 네비게이션)
├── components/           # [UI] 화면을 구성하는 부품들
│   ├── ui/               # shadcn/ui 설치 시 자동 생성되는 폴더
│   ├── common/           # 버튼, 인풋, 모달 등 어디서나 쓰는 부품
│   └── trip/             # 여행 카드, 영수증 아이템 등 도메인 전용 부품
├── hooks/                # [로직] API 호출 및 정산 계산 로직
├── store/                # [상태] Zustand (유저 정보, 정산 항목 바구니)
├── types/                # [타입] TypeScript 인터페이스 정의
└── utils/                # [도구] 금액 포맷팅, 날짜 계산 함수

## 📂 폴더별 세부 파일 구성

### 1. `src/app/` (라우팅 및 페이지)

Next.js App Router의 구조를 따라 페이지를 나눕니다.

- **`layout.tsx`**: 전역 레이아웃. 모바일 웹 환경을 위해 `max-w-md mx-auto` 설정을 넣어 화면 폭을 제한하세요.
- **`page.tsx`**: 홈 화면 (진행 중인 여행 목록).
- **`auth/page.tsx`**: 로그인 페이지 (카카오 로그인 등).
- **`trip/[id]/page.tsx`**: 여행 상세 페이지 (일정 및 영수증 확인).
- **`settle/page.tsx`**: 핵심 기능인 **정산하기** 페이지.

### 2. `src/components/` (UI 부품)

- **`common/`**: 어디서든 쓰이는 공통 부품.
    - `Header.tsx`, `BottomNav.tsx` (모바일 하단 탭 바), `Button.tsx` 등.
- **`trip/`**: 여행 도메인 특화 컴포넌트.
    - `ExpenseItem.tsx` (개별 지출 내역), `TripCard.tsx` 등.
- **`ui/`**: `shadcn/ui` 명령어로 설치한 파일들이 위치합니다 (예: `button.tsx`, `card.tsx`, `checkbox.tsx`).

### 3. `src/hooks/` (서버 데이터 로직)

`TanStack Query`를 사용하여 백엔드 API와 통신하는 커스텀 훅을 모읍니다.

- **`queries/useTripQuery.ts`**: 여행 목록 및 상세 데이터를 가져오는 훅.
- **`mutations/useSettleMutation.ts`**: 최종 정산 데이터를 서버에 전송하는 훅.

### 4. `src/lib/` (라이브러리 설정)

- **`utils.ts`**: `shadcn/ui` 필수 파일 (Tailwind 클래스 합치기용 `cn` 함수 포함).
- **`axios.ts`**: 백엔드 서버와의 통신을 위한 Axios 인스턴스 설정.

### 5. `src/store/` (전역 상태)

- **`useSettleStore.ts`**: **가장 중요한 파일.** 유저가 체크박스로 선택한 "정산 대상 일정 리스트"를 관리합니다.
- **`useAuthStore.ts`**: 로그인한 유저 정보 저장.

### 6. `src/utils/` (순수 계산 로직)

- **`calculator.ts`**: `Decimal.js`를 활용하여 총액을 참여 인원수로 나누는 함수.
    - 예: `calculateSplit(total, peopleCount)` - 소수점 오차 없는 정확한 계산 보장.
- **`formatter.ts`**: 금액에 천 단위 콤마(`,`)를 찍거나 날짜 형식을 변환하는 함수.

### 7. `src/types/` (타입 정의)

- **`index.ts`**: `Trip`, `Expense`, `User` 등 백엔드 API 규격에 맞춘 인터페이스 정의.
